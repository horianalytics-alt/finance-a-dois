# Couple's Finances

Crie um aplicativo de gestão financeira para casais. Preciso de um sistema de autenticação simples onde o usuário possa criar uma 'Família' gerando um código e convidar um parceiro e esse parceiro entrar com o código. O app deve ter um dashboard para adicionar Receitas e Despesas vinculadas ao ID dessa família. Por favor, crie e configure automaticamente as tabelas necessárias no Supabase conectado. O foco absoluto agora é na persistência de dados sem erros de chave estrangeira, a interface pode ser básica.
